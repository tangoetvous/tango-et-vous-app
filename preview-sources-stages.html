SOURCES EMAILS — STAGES

Rôles stockés en DB : 'Guideur(se)' ou 'Guidé(e)' (avec parenthèses, différent des autres formulaires)

Statut : type_confirmation = 'confirme' | 'attente' dans inscriptions_stages

S0 — Notification admin (toute inscription)

POST /api/notify/inscription-stage (sans auth)
Destinataire : tangoetvous@gmail.com
Sujet : 🎭 Inscription stage — ${nom} · ${dateLabels}
Body : { email, prenom, nom, tel, role, statut, saison, inscriptionsParDate[], partEmail?, partPrenom?, partNom? }
inscriptionsParDate : [{ date:YYYY-MM-DD, slots:[{type, theme, horaire_debut, horaire_fin}], tarif }]
Encadré or : Nom/email/tel · Rôle · Dates · Slots+thèmes · Badge statut
Boutons : 📞 tel: · ✉️ mailto: · Ouvrir l'admin → Stages

S1 — Confirmation élève (>3 jours)

POST /api/notify/inscription-stage (sans auth)
Déclencheur : type_confirmation='confirme' ET daysUntil > 3
Sujet : 🎭 Votre inscription au stage du ${firstDateLabel} — Tango & Vous
Bandeau : Vert ✓ "Votre inscription au stage est confirmée"
Stage-box : Pour chaque date : Date · Slots (horaire–horaire — Thème) · Prix
Sources stage-box :
  • Horaires : inscriptionsParDate[i].slots[j].horaire_debut/fin (baked à l'inscription)
  • Thèmes : inscriptionsParDate[i].slots[j].theme
  • Tarif : inscriptionsParDate[i].tarif ou tev_params_stages_${saison}.tarifs
  • Adresse : tev_params_stages_${saison}.adresse
Note rappel : "Vous recevrez un rappel 3 jours avant le stage."
Paiement : "Le règlement se fait sur place. Merci de prévoir l'appoint."
Pas de bouton 👍 : S1 >3j → S4 s'en charge

S1b — Confirmation élève (≤3 jours)

POST /api/notify/inscription-stage (sans auth)
Déclencheur : type_confirmation='confirme' ET daysUntil ≤ 3
Différence S1/S1b : S1b contient le bouton 👍 · pas de mention rappel futur
Bouton 👍 : Vert "Je confirme ma présence" → app.tangoetvous.fr/stages-pwa.html

S2 — Guidée seule en attente

POST /api/notify/inscription-stage (sans auth)
Déclencheur : type_confirmation='attente' (guidée seule → toujours attente)
Sujet : 🎭 Votre demande d'inscription au stage du ${firstDateLabel} — Tango & Vous
Bandeau : Orange ⏳
Stage-box : Même contenu que S1
Encadré parité : "Nous veillons à avoir autant de guideurs que de guidées. Votre inscription sera confirmée selon l'équilibre des inscrits."

S3 — Admin valide attente → confirmé (>3 jours)

POST /api/notify/stage-valide (JWT admin)
Body : { email, prenom, nom, role, inscriptionsParDate[], daysUntil }
Sujet : 🎭 Bonne nouvelle — votre place au stage du ${firstDateLabel} est confirmée !
Bandeau : Vert ✓ "Bonne nouvelle — votre place au stage est confirmée !"
Intro : "Suite à l'évolution des inscriptions..."
Note rappel : si daysUntil > 3 → "Vous recevrez un rappel 3 jours avant le stage."

S3b — Admin valide (≤3 jours)

POST /api/notify/stage-valide (JWT admin)
Différence S3/S3b : daysUntil ≤ 3 → bouton 👍 + pas de mention rappel

S4 — Rappel J-3 (cron)

POST /api/cron/rappel-stage-j3 (X-Cron-Secret)
Déclencheur : Cron quotidien · inscriptions_stages WHERE stage_date=today+3 AND type_confirmation='confirme'
Source : donnees.stagesDetail[i].horaire + .theme (baked à l'inscription — pas les params courants)
Sujet : 🗓 Rappel stage du ${dateLabel} — Tango & Vous
Bandeau : Bleu 🗓 "Rappel — votre stage a lieu dans 3 jours !"
Bouton 👍 : Vert "Je confirme ma présence"
Encadré orange : "Merci de confirmer votre présence. Si vous devez annuler merci de nous prévenir, même au dernier moment."

S-cancel — Admin annule une inscription stage

POST /api/notify/stage-annule (JWT admin)
Body : { email, prenom, nom, inscriptionsParDate[] }
Sujet : ✕ Votre inscription au stage du ${firstDateLabel} a été annulée — Tango & Vous
Bandeau : Rouge ✕ "Votre inscription au stage a été annulée"
Stage-box : Fond rouge · créneaux barrés en rouge
Bouton : Or "Voir les prochains stages →" → stages-pwa.html

Structure stage-box (récapitulatif)

Par date :
📅 Samedi 11 avril 2026
• 14h–15h — Technique
• 15h–16h30 — Thème 1
Prix : 45€

Le règlement se fait sur place. Merci de prévoir l'appoint.
📍 Nom lieu · Adresse · Métro
Horaires baked : donnees.stagesDetail[i].horaire_debut/fin (stockés à l'inscription depuis buildSlots())
Tarifs : inscriptionsParDate[i].tarif || tev_params_stages_${saison}.tarifs
Adresse : tev_params_stages_${saison}.adresse
