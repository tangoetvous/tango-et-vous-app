T1-val — Transfert essai → inscriptions, att. paiement

POST /api/notify/essai-transfert (JWT admin)
Déclencheur : Admin clique "Validé·e" sur une fiche essai tango → statut='attente_paiement'
Body : { email, prenom, nom, role, cours, ville, niveau, saison, partenaire?, assoConnectUrl?, livretUrl? }
Sujet : ✓ Votre inscription au tango est validée — Tango & Vous
Bandeau : Vert ✓ "Votre inscription au tango est validée — finalisez votre inscription"
Intro : "Suite à votre cours d'essai, nous sommes ravis de vous accueillir dans nos cours de tango pour la saison..."
Cours-box : Cours · Prochain cours (date depuis tev_cours_dates) · Horaire · Lieu (tev_params_${ville}_${saison}.adresse) · Rôle (badge) · Statut ✓ Validé·e · Partenaire (si renseigné)
Bouton AssoConnect : Or → body.assoConnectUrl (depuis tev_liens_assoconnect[saison].cours)
Note : "Votre place sera réservée une fois l'inscription en ligne et le premier paiement effectués."
Quelques précisions : Avertissement 2 emails différents en couple (encadré rouge) · Modes paiement (CB 1×/3×, espèces, chèque) · Note pourboire 0€
Sorano : si ville='vincennes' → encadré jaune "🏛 Adhésion à l'Espace Sorano" (lien #LIEN_SORANO_A_RENSEIGNER)
Livret : si livretUrl → bouton contour bleu "📖 Télécharger le livret →"
Admin — encadré or : Nom/email/tel/rôle/cours/statut ✓

CB3x — Rappel échéance paiement CB 3 fois

POST /api/cron/rappel-cb3x (X-Cron-Secret)
Déclencheur : Cron mensuel · élèves avec paiement='cb3x' dont la prochaine échéance tombe dans 7 jours
Source échéances : inscriptions_cours.donnees.datesPaiement[i] — 3 dates calculées à l'inscription par l'admin
Body interne : { email, prenom, nom, montant_echeance, date_echeance, num_echeance (2 ou 3), cours }
Sujet : 💳 Rappel — Prochaine échéance CB (${num_echeance}/3) — Tango & Vous
Bandeau : Bleu 💳 "Rappel — prochaine échéance de paiement"
Contenu : Échéance N/3 · Date · Montant · Cours · "Votre CB sera débité automatiquement via AssoConnect"
Bouton : "Accéder à mon espace élève →" → app.tangoetvous.fr
Signature : Florencia GARCIA & Jérémy BRAITBART · Tango & Vous
Note : ⚠️ À implémenter : nécessite que l'admin renseigne les dates CB3x dans donnees.datesPaiement lors de l'inscription
