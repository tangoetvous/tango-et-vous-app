CP-A — Carte pointée (notification admin immédiate)

POST /api/notify/carte-pointage (sans auth)
Déclencheur : L'ÉLÈVE pointe lui-même — depuis son espace (index.html) ou en scannant le QR code (pointer.html), en fire and forget.
⚠️ Ne pas confondre avec POST /api/notify/carte-pointee-admin (handleNotifyCartePonteeAdmin), déclenché quand c'est l'ADMIN qui pointe : celui-là n'envoie aucun email admin — il pose la notif in-app de l'élève, met CP-E en file pour le lendemain matin et envoie un push à l'élève.
Body : { email, prenom, nom, date, nbAdded, utilises, restants, source ('app'|'qr'|'admin') }
Destinataire : tangoetvous@gmail.com
Sujet : 🃏 [Carte 10] ${nom} a pointé — ${nb} cours ce jour · ${état carte}
Encadré or : Nom/email · Table : "⬤ Cours pointés CE JOUR" (vert en évidence) · Utilisés au total · Restants · Expiration
Bouton : "Ouvrir l'admin → Cartes 10"
Notif admin : notifications — INSERT type 'carte_pointage', lien_tab:'cartes'
