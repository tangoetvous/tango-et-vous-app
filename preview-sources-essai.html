SOURCES EMAILS — COURS D'ESSAI TANGO

Handler principal : handleNotifyInscriptionEssai · Fichier : worker.js

E0 — Notification admin (toute inscription)

POST /api/notify/inscription-essai (sans auth)
Destinataire : tangoetvous@gmail.com
Sujet : `🎭 Essai tango — ${prenom} ${nom} · ${ville} ${niveau} · ${dateEssai}`
Nom élève : body.prenom + body.nom
Email : body.email
Tél : body.tel
Rôle : body.role 'guideur'|'guidee'|'double'
Ville : body.ville 'paris'|'vincennes'
Niveau : body.niveau 'debutant'|'intermediaire'
Date essai : body.dateEssai YYYY-MM-DD
Partenaire : body.partPrenom + body.partNom si avecPart=true
Statut : body.statut 'confirme'|'attente'
Lieu : tev_params_${ville}_${saison}.adresse.nom + .rue + .transport
Horaire : tev_params_${ville}_${saison}.horaires.${niveau}
Boutons : 📞 tel: · ✉️ mailto: · 💬 sms: · Ouvrir l'admin

E1 — Confirmation élève (>7 jours)

POST /api/notify/inscription-essai (sans auth)
Déclencheur : statut='confirme' ET daysUntil > 7
Destinataire : body.email
Sujet : ✓ Votre cours d'essai du ${dateLabel} est confirmé — Tango & Vous
Bandeau : Vert ✓ "Votre cours d'essai est confirmé !"
Cours box : Date · Cours · Horaire · Lieu · Rôle (badge) · Statut "✓ Confirmé·e"
Horaire : tev_params_${ville}_${saison}.horaires.${niveau}
Adresse : tev_params_${ville}_${saison}.adresse.nom + .rue
Note rappel : "Vous recevrez un rappel 7 jours avant le cours."
Boutons : ✕ Annuler (lien API) · ↩ Reporter (formulaire essai)
Livret : tev_params_${ville}_${saison}.livret.url_deb (débutant) / url_int (intermédiaire)
Checklist : débutant uniquement — arrivée 5min · chaussures lisses · tenue
Pas de bouton 👍 : E1 >7j → pas de bouton confirmer présence (E4/E6 s'en charge)

E2 — Guidée seule en attente

POST /api/notify/inscription-essai (sans auth)
Déclencheur : statut='attente' (guidée seule → toujours attente)
Destinataire : body.email
Sujet : ⏳ Votre demande de cours d'essai tango — liste d'attente — Tango & Vous
Bandeau : Orange ⏳ "Votre demande est bien enregistrée"
Encadré : Explication parité guideurs/guidées
Bouton : Nous contacter (mailto admin)

E4 — Rappel J-7 (cron)

POST /api/cron/essai-rappel-j7 (X-Cron-Secret)
Déclencheur : Cron quotidien · inscriptions_essai WHERE date_essai = today+7 AND statut='confirme' AND type='tango'
Destinataire : e.email (depuis inscriptions_essai)
Sujet : 🗓 Rappel — votre cours d'essai du ${dateLabel} — Tango & Vous
Bandeau : Bleu 🗓 "Rappel — votre cours d'essai a lieu dans 7 jours !"
Cours box : Date · Cours · horaires depuis tev_params_${ville}_${saison} · Lieu
Bouton 👍 : Vert "Je confirme ma présence" → /api/essai/confirmer?id=&token=j7
Boutons : ✕ Annuler → /api/essai/annuler · ↩ Reporter → cours-essai.html
Checklist : débutant uniquement

E5 — Guideur seul en attente (quota sept-nov)

POST /api/notify/inscription-essai (sans auth)
Déclencheur : statut='attente' + role='guideur' + quota GUI≥22 + mois 9/10/11
Bandeau : Orange "Ce créneau est complet pour votre rôle ce jour-là"
Boutons : ↩ Reporter · Nous contacter

E6 — Confirmation élève (<7 jours)

POST /api/notify/inscription-essai (sans auth)
Déclencheur : statut='confirme' ET daysUntil ≤ 7
Différence E1/E6 : E6 contient le bouton 👍 "Je confirme ma présence", pas de mention rappel futur
Bouton 👍 : Vert · position : APRÈS cours box, AVANT annuler/reporter

E15 / E15b — Admin valide attente → confirmé

POST /api/notify/essai-valide (JWT admin)
Body : { email, prenom, nom, ville, niveau, dateEssai, role, partPrenom?, partNom?, emailPartage?, daysUntil, livretUrl?, id }
E15b : si emailPartage=true → salutation "Prénom & Prénom", sinon E15 normal
Sujet : ✓ Bonne nouvelle — votre cours d'essai du ${dateLabel} est confirmé !
Texte intro : "Suite à l'évolution des disponibilités..."
Bouton 👍 : si daysUntil ≤ 7 · sinon → mention rappel J-7

E-mod — Modification par l'admin

POST /api/notify/essai-action (JWT admin) avec action='edit-essai'
Body : { action:'edit-essai', essai:{}, newDate, newVille, newNiveau }
Bandeau : Bleu 📋 "Votre cours d'essai a été modifié"
Cours box : Ancienne date barrée rouge · Nouvelle date en vert
Bouton : ✕ Annuler

E-J1a — Lendemain du cours, élève présent

POST /api/cron/essai-j1 (X-Cron-Secret)
Déclencheur : Cron 9h Paris · inscriptions_essai WHERE date_essai=hier AND presence_declaree=true
Sujet : 🎶 À bientôt sur la piste — et si vous rejoigniez nos cours ?
Bandeau : Vert ✓ "À bientôt sur la piste !"
Contenu : Présentation du process d'inscription · bouton AssoConnect
Pas de lien autre essai : l'essai a eu lieu → pas de lien formulaire essai

E-J1b — Lendemain du cours, élève absent

POST /api/cron/essai-j1 (X-Cron-Secret)
Déclencheur : Cron 9h Paris · presence_declaree=false (null → pas d'email)
Sujet : 💙 On vous attend bientôt — Tango & Vous
Bandeau : Orange 💙 "Vous nous avez manqué"
Bouton : ↩ Choisir une nouvelle date → cours-essai.html
Note : "Pas de pénalité · vos cours gratuits de septembre restent valables"
