SECTION 4 — RÈGLES DE CODE STRICTES (admin.html)
────────────────────────────────────────────────────────────────────────────────

1. JS vanilla uniquement : var / function — PAS de const/let/arrow functions
   dans les strings HTML générées via innerHTML

2. ZÉRO onclick inline dans le HTML généré dynamiquement

3. ZÉRO prompt() / ZÉRO confirm() — remplacés par modals HTML :
   - #modal-date    → saisie date
   - #modal-confirm → confirmation

4. Tous les boutons utilisent :
   data-action="nom-action"
   data-id="..."
   (+ autres data-* selon besoin)

5. handleAction(btn) est le point d'entrée central pour tous les clics

6. bindTabEvents(el) DOIT être appelé après chaque renderTab()
   pour attacher les event listeners au contenu dynamique

7. Apostrophes dans strings JS simples → utiliser &#39; ou guillemets doubles
   Exemple correct : +'<div>L&#39;élève est inscrit.</div>'
   Exemple INCORRECT : +'<div>L\'élève est inscrit.</div>'

8. Toujours vérifier l'équilibre { } après modification :
   node --check fichier.js  (extraire le bloc <script> d'abord)

9. Les modals #modal-date et #modal-confirm remplacent prompt()/confirm()
   partout, y compris dans Safari iOS où ces fonctions sont bloquées

── ONGLET 1 : COURS TANGO ──

Flux des statuts (dans cet ordre strict) :
  demande → valide → attente_paiement → inscrit

6 sous-onglets :
  "Demandes"          → nouvelles demandes reçues, bouton "✓ Valider"
  "Demande validée"   → demandes validées par nous, bouton "→ Attente paiement"
  "Attente paiement"  → bouton "💳 Valider paiement" (ouvre formulaire)
  "Inscrits"          → paiement confirmé
  "✏️ Nouvelle demande" → renvoie vers inscription-cours.html (même formulaire que l'élève)
  "💳 Valider paiement" → formulaire complet (sélection élève, type, paiement, montant)

Validation paiement → inscrit l'élève ET crée sa carte de 10 si type = carte10

Stats des 4 statuts affichées en temps réel en haut de l'onglet

── ONGLET 2 : ESSAI ──

Trié par : date ASC, puis niveau (débutant avant intermédiaire), puis rôle
Groupé par : date + niveau (pas juste par date)
  → en-tête de groupe montre "Débutant" ou "Intermédiaire & Avancé"
Fiches partenaires : affichées SÉPARÉMENT sous chaque fiche inscrit
  (pas fusionnées avec la fiche principale)
Guidées en attente : bouton "✓ Confirmer" dans la vue Attente

── ONGLET 3 : CARTES 10 ──

Semaines sans cours : dans SANS_COURS_PARIS[] et SANS_COURS_VINCENNES[]
Cartes apparaissent automatiquement dans cet onglet après validation paiement
  carte10 dans "Valider paiement" de l'onglet Cours Tango

── ONGLET 4 : STAGES ──
