SOURCES EMAILS — INSCRIPTIONS TANGO RÉGULIER

I0 — Notification admin (toute nouvelle inscription)

POST /api/notify/inscription-cours (sans auth)
Destinataire : tangoetvous@gmail.com
Header admin : Fond #111 · bordure or · "Nouvelle inscription [tango/preinscription]"
Sujet : 🎓 Inscription tango — ${nom} · ${cours}
Body : { email, prenom, nom, tel, role, ville, niveau, saison, statut, partenaire?, emailPartenaire?, type }
Encadré or : Nom/email/tel · Rôle (badge couleur) · Cours · Statut
2 cours : si 2 cours → 2 encadrés or distincts
Boutons : 📞 tel: · ✉️ mailto: · 💬 sms: · Ouvrir l'admin → Inscriptions Tango

I01 — Guideur ou couple, att. paiement

POST /api/notify/inscription-cours (sans auth)
Déclencheur : statut='attente_paiement' (guideur seul ou couple)
Sujet : ✓ Votre inscription au tango ${saison} — Tango & Vous
Preheader : "Votre inscription tango est validee - finalisez votre dossier sur AssoConnect"
Bandeau : Vert ✓ "Votre inscription au tango est validée — finalisez votre inscription"
Cours box : Cours · Saison · Rôle · Statut "✓ Att. paiement" · Partenaire (si couple)
Bouton AssoConnect : tev_liens_assoconnect[saison].cours (depuis admin Paramètres)
Sorano : si ville='vincennes' → encadré jaune 🏛 Adhésion Sorano
Quelques précisions : Avertissement 2 emails différents en couple · Modes paiement CB/espèces/chèque
Livret : tev_params_${ville}_${saison}.livret.url_deb / url_int

I01-att — Guidée seule, att. validation

POST /api/notify/inscription-cours (sans auth)
Déclencheur : statut='demande' (guidée seule dans tous ses cours)
Preheader : "Votre demande inscription tango enregistree - en attente de validation admin"
Bandeau : Orange ⏳ "Votre demande d'inscription est enregistrée — liste d'attente"
Encadré : Explication parité · 3 options (attente / autre créneau / cours d'essai)
Signature : signWait — "Nous reviendrons vers vous très prochainement." (≠ signEleve — destinataire pas encore confirmé, évite le clipping Gmail)

I02 — Admin valide guidée → att. paiement

POST /api/notify/inscription-cours-validee (JWT admin)
Body : { email, prenom, nom, tel, role, ville, niveau, saison, partenaire?, emailPartenaire?, livretUrl?, assoConnectUrl? }
Sujet : ✓ Votre demande d'inscription au tango est validée — Tango & Vous
Preheader : "Votre inscription tango est validee - finalisez votre dossier sur AssoConnect"
Bandeau : Vert ✓
Cours box : Cours · Saison · Rôle · Statut ✓ Validé·e · Partenaire
Bouton AssoConnect : Or → body.assoConnectUrl
Sorano : si ville='vincennes' → encadré jaune
Quelques précisions : Modes paiement
Livret : si livretUrl
Signature : signI02 — "Nous vous attendons avec impatience !" (≠ signEleve — évite le clipping Gmail avec les emails I01-val qui ont le même contenu final)

I03 — Admin valide paiement → inscrit

POST /api/notify/inscription-cours-payee (JWT admin)
Body : { email, prenom, nom, saison, coursInfos: [{ville, niveau, role}] }
Backward compat : ville, niveau, role au niveau racine si mono-cours (coursInfos absent ou vide)
Sujet (1 cours) : ✓ Votre inscription au tango est confirmée — à bientôt !
Sujet (2 cours) : ✓ Vos inscriptions au tango sont confirmées — à bientôt !
Preheader : "Inscription confirmee ${ville1 label} ${niveau1 label} [+ ${ville2} ${niveau2}] - nous vous attendons avec impatience"
Dynamique — liste les cours inscrits, ASCII sans accents · calculé dans le handler depuis coursInfos
Bandeau : Vert ✓ — "Inscriptions confirmées" au pluriel si 2 cours
Intro : "Votre inscription au cours de ${coursResume} est confirmée..."
coursResume = coursInfos.map(ci => villeLabel + ' — ' + niveauLabel).join(' & ')
Cours boxes : coursInfos.map() → une div.cours-box par cours
Titre : "VOTRE INSCRIPTION CONFIRMÉE" (1 cours) ou "COURS 1 — PARIS DÉBUTANTS" (2 cours)
Par cours : Cours · Prochain cours · Heure · Lieu · Rôle (badge) · ✓ Inscrit·e
Horaires : tev_params_${ville}_${saison}.horaires[niveau] (Supabase → parametres)
Adresse : tev_params_${ville}_${saison}.adresse (Supabase → parametres)
Prochain cours : première date >= aujourd'hui dans tev_cours_dates.${ville} (Supabase → parametres)
PWA : Bloc violet iPhone/Android → app.tangoetvous.fr
Livrets : Un bouton par (ville, niveau) distinct dans coursInfos
URL : tev_params_${ville}_${saison}.livret.url_deb ou .url_int selon niveau (Supabase → parametres)
Bouton omis si URL vide
J+7 : Déclenche le cron P1 (espace élève) 7 jours plus tard

Sujet : 📋 Votre inscription a été modifiée — Tango & Vous
Preheader : "Votre inscription a ete modifiee - retrouvez les nouveaux details ci-dessous"
Bandeau : Bleu 📋
Cours box : Ancien cours barré rouge · Nouveau cours en vert
Bouton : Nous contacter (mailto admin)

I17 — Mode pré-inscription (mai-août)

POST /api/notify/inscription-cours (sans auth) avec mode='preinscription'
Déclencheur : MODE === 'preinscription' (mai-août)
Sujet : ✓ Votre pré-inscription tango ${saisonSuivante} — Tango & Vous
Différence : Badge "Saison prochaine" · mention "reprise en septembre" · tarifs prochaine saison
Tarifs : localStorage.tev_tarifs_prochaine_saison (admin) → body.tarifs

Règles guideur/guidée (rappel)

Guidée seule → tous ses cours : statut='demande' → I01-att
Guideur seul ou couple : statut='attente_paiement' → I01
2 cours : 2 emails distincts — quota vérifié indépendamment par cours
Couple email partagé : un seul email avec 2 prénoms
CAP_GUI=22, CAP_GDE=23 : comptés depuis inscriptions_cours statut IN ['inscrit','attente_paiement']
