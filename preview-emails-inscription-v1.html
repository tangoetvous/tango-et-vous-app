⚠️ Le push OS n'est pas encore implémenté pour les inscriptions cours régulier (TODO dans CLAUDE.md). Il nécessite VAPID key + table fcm_tokens + Edge Function Supabase.

Ce qui détermine la variante — tout se joue dans le même handler handleNotifyInscriptionCours :

• liste d'attente : isWaitlist envoyé par le formulaire, ou rôle « guidée » sans partenaire sur le 2ᵉ cours
• duo : venue === 'avec-part' et un prénom de partenaire renseigné
• Vincennes : ville === 'vincennes' → ajoute l'encadré Sorano

⚠️ « I17 — pré-inscription » n'existe pas dans le code. Le handler n'a aucune notion de pré-inscription : en mai-août, c'est exactement le même email, avec simplement la saison suivante dans saison.

Données d'exemple — les valeurs affichées (horaires, adresse, livret, lien AssoConnect, prochain cours) proviennent de paramètres factices ; en production elles sont relues dans les Paramètres au moment de l'envoi. 29 emails produits pour cette page.
